# Sizing & layout

Almost every component here is in one of two groups. Putting one in the wrong kind of container is
the usual reason a viewer comes up empty.

| | Behaviour | You supply |
| --- | --- | --- |
| **Fills its parent** | root is `width: 100%; height: 100%` with a small `min-height` floor | a parent with a definite height |
| **Content-sized** | grows to fit its content | nothing; drop it in a flow layout |

Graph viewers, charts and editors fill their parent. Chips, bars, strips, inputs and stat cards are
content-sized. The [per-component list](#component-sizing) is at the bottom of this page.

## The height rule

`height: 100%` against a parent of `height: auto` resolves to nothing. A viewer in that position
collapses to its `min-height` floor, which reads as a squashed graph, or to zero, which reads as a
blank box.

```tsx
// Works: the box has a definite height.
<div style={{ height: 480 }}>
  <DFGViewer data={dfg} />
</div>

// Works: flex child with minHeight: 0 inside a sized column.
<div style={{ display: "flex", flexDirection: "column", height: "100vh" }}>
  <Toolbar />
  <div style={{ flex: 1, minHeight: 0 }}>
    <DFGViewer data={dfg} />
  </div>
</div>

// Collapses: nothing above resolves to a height.
<div>
  <DFGViewer data={dfg} />
</div>
```

`minHeight: 0` on the flex child is not optional. A flex item defaults to `min-height: auto` and
refuses to shrink below its content. Without it, a tall graph pushes the column past its bounds and
the page scrolls instead of the viewer.

## Where the export frame fits

[`ViewerExportFrame`](?path=/docs/getting-started-image-export--docs) is `position: relative` and
takes a `style`, so it can be the sizing box instead of another nested `div`:

```tsx
<ViewerExportFrame filename="dfg" style={{ height: 480 }}>
  <DFGViewer data={dfg} />
</ViewerExportFrame>
```

In a dockable panel or a full-height shell, hand it the panel's size:

```tsx
<ViewerExportFrame style={{ width: "100%", height: "100%", display: "flex", flexDirection: "column" }}>
  <div data-export-root style={{ flex: 1, minHeight: 0, position: "relative" }}>
    <OCDFGViewer data={ocdfg} />
  </div>
</ViewerExportFrame>
```

## Theme and stylesheet

Everything renders inside a Radix `Theme`. One at the app root covers it. Nest another only to run a
subtree in the opposite color scheme.

```tsx
import "@r4pm/components/styles.css";
import { Theme } from "@r4pm/components";

<Theme>
  <App />
</Theme>;
```

The root `Theme` carries `min-height: 100vh`. That is right for a full-page app and wrong when you
embed a single viewer in someone else's page, where it stretches the whole viewport. Override it
there:

```tsx
<Theme style={{ minHeight: 0 }}>
  <div style={{ height: 400 }}>
    <PetriNetViewer data={net} />
  </div>
</Theme>
```

Components with their layout intact and no styling mean the stylesheet is missing or imported in the
wrong order. See [Introduction](?path=/docs/getting-started-introduction--docs).

## Scrolling and overflow

Viewers that fill their parent handle their own interior scrolling, whether that is a pan-and-zoom
canvas or virtualized rows. Wrapping one in an `overflow: auto` container defeats that. The outer
scroller resolves to the content height and takes over. Content-sized components are the opposite and
expect the page to scroll.

## Dark mode

Color scheme comes from the Radix `Theme` (`appearance="light" | "dark" | "inherit"`). Viewers read
the resolved scheme, and graphs, charts and exported images follow it with no extra wiring. Charts
and SVG export resolve theme tokens to concrete colors while rendering, so an exported image keeps
the colors it had on screen.

## Common failure modes

| Symptom | Cause | Fix |
| --- | --- | --- |
| Viewer blank or a few pixels tall | no definite height above it | give an ancestor a height |
| Graph squashed to ~256px | collapsed to the `min-height` floor | same |
| Page scrolls instead of the viewer | flex child without `minHeight: 0` | add it |
| Layout right, styling missing | `styles.css` not imported, or imported before your Tailwind entry | fix the import order |
| Viewer stretches to the whole viewport | root `Theme`'s `min-height: 100vh` | `<Theme style={{ minHeight: 0 }}>` |
| Graph nodes in a plain row or column | no `viz` configured | see [Graph Layout](?path=/docs/getting-started-graph-layout--docs) |
